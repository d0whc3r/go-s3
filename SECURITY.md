# Security Policy

## Supported Versions

Security fixes are applied to the latest release on the `master` branch.

| Version | Supported |
| --- | --- |
| Latest (`master`) | Yes |
| Older releases | No |

## Reporting a Vulnerability

If you discover a security vulnerability in **go-s3**, please do **not** open a public GitHub issue.

Instead, please report it privately using one of the following methods:

1. **GitHub Security Advisories**: Use the [Report a vulnerability](https://github.com/d0whc3r/go-s3/security/advisories/new) button on the repository's Security tab.
2. **Email**: Contact the maintainer directly with a description of the issue and steps to reproduce.

### What to include

- A clear description of the vulnerability and its potential impact.
- Steps to reproduce or a minimal proof of concept.
- Affected version(s) and environment details (OS, Go version, S3 provider if relevant).

We will acknowledge receipt of your report as soon as possible and work with you to validate, fix, and coordinate disclosure.
